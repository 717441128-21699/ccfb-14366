# 守城 / 攻城 AI 系统

用 **影响力地图 + 行为树** 替换原有「一堆 if」的守城 AI,并新增带多步战术依赖的攻城 AI。
纯 TypeScript 实现,核心模拟与 AI 不依赖 DOM,可在 Node/Worker/浏览器同构运行。

## 需求达成对照

| 需求 | 实现 | 验证 |
| --- | --- | --- |
| 影响力地图综合兵力/射程/城墙完整度/视野,256×256 更新 <10ms | `src/core/influence.ts`,每层一个 `Float32Array(256²)`,预算径向核 + 空间哈希 | `npm run perf`,实测 p95 ≈ 0.9ms |
| 守城 AI 识别佯攻、留预备队,同一招连续打穿率 <20% | `src/ai/defender.ts` 行为树:佯攻识别(承诺度+持续度双条件)、预备队底线、突破应急 | `npm test`,普通/困难档所有战术连续打穿率 <20% |
| 攻城 AI 挖地道/架云梯/断水源多步战术,步骤间有依赖 | `src/ai/attacker.ts`,`TacticStep.dependsOn` 显式依赖,前置未完成不激活 | `test/tactics.test.ts` |
| 三档难度只靠信息量与反应速度,不加兵 | `src/core/roster.ts` 的 `DIFFICULTY`:视野倍率/决策周期/确认 tick/预警开关;双方兵力与兵种数值完全相同 | `test/batch.test.ts` 校验三档兵力一致 |
| AI 编辑页看行为树 | Web「AI 编辑页」:树结构、节点判定逻辑、各档感知参数、兵种数值 | `npm run dev` |
| 复盘页逐秒看 AI 当时判断依据 | Web「复盘页」:地图回放 + 扇区威胁热力 + 行为树激活高亮 + 叶子 evidence + 决策时间线 | `npm run dev` |
| 地图和兵种自行生成 | `src/core/mapgen.ts`(256² 城/墙/八门/护城河/水源)、`src/core/roster.ts`(7 兵种) | — |

## 目录结构

```
src/core/   类型、兵种表、难度配置、地图生成、影响力地图
src/sim/    World(移动/接战/迷雾/工程/胜负)、引擎、批量模拟
src/ai/     行为树框架 bt.ts、守城 defender.ts、攻城 attacker.ts
src/web/    React 工作台(编辑页 + 复盘页)
scripts/    perf 性能基准、batch/matrix 批量统计、baseline 旧if对照、smoke 冒烟
test/       vitest 用例
```

## 命令

```bash
npm install
npm run dev      # 启动 Web 工作台(AI 编辑页 / 复盘页)
npm test         # vitest:影响力地图性能、战术依赖、连续打穿率硬指标
npm run perf     # 影响力地图 256² 更新耗时基准(要求 p95 < 10ms)
npm run batch    # 批量模拟:各战术×难度破城率/连续打穿率
npm run baseline # 旧 if-AI 与新行为树守城对比
npm run build    # 类型检查 + 生产构建
```

## 关键设计

### 影响力地图
五层 `Float32Array`:兵力 `force`、即时威胁 `threat`、远程火力 `ranged`、视野 `vision`、
城墙完整度 `wall`。敌方单位只有通过战争迷雾被看见时才计入威胁层,并按情报新鲜度衰减;
同时聚合到 8 个城墙扇区供行为树直接读取。径向核预计算缓存,接敌检测用 16 格空间哈希。

### 守城行为树
`顺序(初始化 → 并行(感知, 佯攻识别) → 选择(突破应急, 水源守卫, 工兵预警) → 选择(增援[预备队底线], 回收, 驻守))`。
- 佯攻识别:兵力承诺度低于阈值且持续观测不足 → 标记佯攻,不抽预备队。
- 预备队底线:简单 15% / 普通 35% / 困难 40%,低于底线拒绝继续抽调。
- 突破应急:难度门控确认延迟(简单 18 tick、困难 3 tick)与投入队数(2/3/4)。

### 攻城战术步骤依赖
每个战术是一条带 `dependsOn` 的步骤链,例如断水源:
`接近渠首 → 破坏(依赖接近) → 等脱水(依赖破坏) → 强攻(依赖脱水)`。
前置步骤未 `done`,后继不会激活;停滞过久自动兜底转全军强攻。

### 难度如何只靠信息/反应
- 视野倍率 0.55 / 0.8 / 1.0,墙顶哨位警戒半径随之缩放。
- 决策周期 15 / 8 / 4 tick,敌情确认 18 / 8 / 3 tick。
- 简单档关闭工兵预警与水源守卫,雾中目标守军命中率下降。
- 三档双方兵种、数量、属性完全一致,无任何数值加成。
